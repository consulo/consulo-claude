# Claude

[Claude](https://claude.com) by Anthropic as an AI provider for Consulo.

Chats run through the [Claude Code](https://docs.claude.com/en/docs/claude-code) command line (`claude`), one
long-lived process per chat, in the project directory. Sign in with the command line's own login, an Anthropic API key,
or an OAuth token from `claude setup-token`. Tool permission prompts and questions of the model are answered in the
AI Chat tool window.
